# A REFUSAL IS A CLAIM ABOUT WHAT THIS LAYER CANNOT DO, and a claim held only in prose drifts: a door quietly
# acquiring a real implementation is an improvement nobody records, and a real door quietly becoming a refusal is
# a regression nobody sees. So the count is written down here and `refusal_census.cmake` recomputes it on every
# build, in BOTH directions — a file with a refusal it does not list fails, and a listed count that has moved fails.
# Changing this file is therefore the deliberate act of adding or removing a refusal, and the diff says which.
#
# THE FORMAT IS `file count`, one per line, and the total is the sum: see the `total:` line at the foot, which is
# the number the gate reads.
#
# **AND THE NEEDLE IS WIDENED TO SEE BOTH WAYS A REFUSAL IS SPELLED, WHICH IS WHAT CLOSES A HOLE THIS FILE ALREADY
# ADMITTED.** A refusal is either the `APPKIT-REFUSE` literal at the site or a call to `fn_refuse_window`, the shared
# helper `AppKitRefusal.h` exists to keep the wording in one place. The census counted only the literal, so the
# 126 sites written through the helper — half the refusals in the library, and every new one — moved no number at
# all, which is the drift this instrument exists to prevent. It now counts `APPKIT-REFUSE|fn_refuse_window`, and the
# count went 141 -> 267 for that reason ALONE: no refusal was added or removed by the widening.
#
# AND IT ROSE BY ONE IN THE APPLICATION SLICE: `-application:printFiles:`, which needs the printing system and the Apple
# Event that would deliver a print request.
#
# AND IT ROSE BY ONE IN THE INPUT-CONTEXT SLICE: selecting a keyboard layout this machine's XKB data cannot build.
#
# AND IT ROSE BY THREE IN THE TEXT-LAYER SLICE, ALL IN `NSSpellChecker`: the asynchronous check (its results would be
# `NSTextCheckingResult`s, which Foundation here has not got, so it refuses as `-checkString:` already does), the
# substitutions panel's accessory controller (no panel), and the grammar string (no engine).
#
# AND IT ROSE BY ONE IN THE ALERT SLICE: the help button's action, whose delegate may decline to handle the request and
# whose anchor then has no Help Viewer to open in.
#
# AND IT ROSE BY SEVEN IN THE IMAGE SLICE: three format flags a bitmap rep cannot hold, the two TIFF doors, the name with
# no space behind it in `-colorSpace`, and the narrowed reason `-bitmapImageRepByConvertingToColorSpace:` still refuses
# (the reason changed; the site is the same one, counted again by the re-pin because the count is per file).
#
# AND IT ROSE BY EIGHT WHEN THE COMBO BOX'S ROWS BECAME A DATA SOURCE'S: seven refusals for the array doors a
# source replaces and the three list doors the session has no mechanism for, plus one that was already in the file.
#
# AND IT ROSE BY FIVE IN THE COLOUR-PANEL SLICE, ALL DELIBERATE: `NSColorList`'s four (the three mutators of a list that
# came from a system directory, and a standard-path write of one), and one in `NSColor.m` — the CATALOG LOOKUP stopped
# being a refusal when `NSColorList` landed, but it still names the two cases it cannot answer (no such list, no such
# key), and a site is a site.
#
# THE COUNT IS A FILE'S MENTIONS RATHER THAN ITS EXECUTED STATEMENTS, and that was already true before the widening
# (`NSCell.m`'s six are all prose). It is a per-file DRIFT detector: a file that gains or loses a refusal changes a
# line, and a file whose comment names one has to keep naming it.
