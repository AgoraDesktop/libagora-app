# A REFUSAL IS A CLAIM ABOUT WHAT THIS LAYER CANNOT DO, and a claim held only in prose drifts: a door quietly
# acquiring a real implementation is an improvement nobody records, and a real door quietly becoming a refusal is
# a regression nobody sees. So the count is written down here and `refusal_census.cmake` recomputes it on every
# build, in BOTH directions — a file with a refusal it does not list fails, and a listed count that has moved fails.
# Changing this file is therefore the deliberate act of adding or removing a refusal, and the diff says which.
#
