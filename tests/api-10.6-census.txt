# The third census in this suite, and the one that measures the OTHER direction. `refusal_census.txt` holds what the
# implementation says it cannot do; `owed_census.txt` holds what the headers say they do not do yet; both are claims
# written in this tree's own voice. THIS ONE IS THE MEASUREMENT THOSE CLAIMS ARE ABOUT — the fraction of Apple's
# 10.6 AppKit surface that a caller can actually reach — and it exists because that number was, until now, produced
# by hand and never the same twice: three separate counts of "what is missing in libagora-app" gave 4%, 44% and 54%,
# each measuring a different thing (progress on the 10.11 gap list, header filenames, `@implementation` blocks).
# A number nobody can recompute is not a measurement.
#
# **THE REFERENCE IS 10.6 RATHER THAN 10.11, AND THAT IS THE TREE'S OWN CHOICE RATHER THAN A CONCESSION.**
# `COCOA-10.11-SURFACE-PLAN.md` §2.1 records it: "The tree's own reference today is 10.6 … `libagora-app`'s era pins
# are 10.2/10.5/10.6. The 10.11 SDK is therefore a NEW reference, not a replacement." Measuring against 10.11 charges
# this tier for 47 classes that only exist in 10.7–10.11 and that no slice has promised yet; measuring against 10.6
# asks the question the tree is actually answering. The plan's own §0 verdict is the same finding this census
# produces: the gap is not the 10.7–10.11 delta, it is the 10.6 surface this tree never finished.
#
# **THE SDK IS NOT IN THIS REPOSITORY AND MUST NOT BE.** Apple's headers are not redistributable. What the plan
# commits, and what is committed here, is the RECIPE plus the generated NAME MANIFEST: `tools/api-ledger manifest`
# reads an SDK checkout and emits facts — class names, superclasses, protocol names, selector names, function
# names — and `api/10.6/appkit-manifest.txt` holds them. No declaration, comment, annotation or line of Apple's
# expression is copied; a manifest of names is the same kind of fact as a symbol table, which is why it can be
# committed at all. Regenerating it needs the SDK and is documented in `api/10.6/README.md`.
#
# **INHERITANCE IS RESOLVED, WHICH IS WHAT MAKES THIS A MEASUREMENT RATHER THAN A DIFF.** The plan requires it in as
# many words (§2.4: the probe must answer for inherited methods, because that is what `respondsToSelector:` does). So
# an Apple selector counts as present when this tree declares it on the class, inherits it from a local superclass, or
# implements it in a `.m` body anywhere along that chain — and `@property` is expanded to getter and setter, because
# an accessor is a door a caller sends. Without this the ledger reported `NSTextView 0 of 130` for a class that
# inherits most of its surface from `NSText`, which is the single most instructive false negative this instrument has
# produced.
#
# **AND THE COMMENT LINES IN THIS BLOCK ARE PROSE, WHICH IS TO SAY THEY CAN GO STALE.** The metrics below are pinned
# and the gate fails if one moves; the four lines above are hand-written summaries of them, and this file carried
# "80 declared" for three slices after the number became 86 — the gate did not notice, because a comment is not a
# metric. Recompute them when you re-pin, from `api-ledger census`, rather than editing the numbers by eye.
#
